# 大阪石材 AIチャットボット・管理画面（試作）

大阪石材（https://www.osaka-sekizai.jp/）のホームページ向けAIチャットボットと、その管理画面のUI/UX試作です。

**現在のスコープ：フェーズ1・UI/UXのみ。** バックエンドや外部API（Supabase / Anthropic Claude API / Voyage AI）は使用していません。データはすべてブラウザ内の仮データ（`localStorage`）で、AIの回答は「登録されたFAQとの簡易一致」によるダミー応答です。将来の本実装に向けた要件・設計判断・用語ルールは [`CLAUDE.md`](./CLAUDE.md) にまとめています。

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:3000` を開くと、下記2つの画面へのリンクがあるトップページが表示されます。

## 画面

| URL | 内容 |
| --- | --- |
| `/admin` | 管理画面ホーム（使い方の3ステップ） |
| `/admin/sources` | 「AIに覚えさせる情報」（URL・PDF・テキストの登録、一覧管理） |
| `/widget-demo` | お客さま向けチャットの見た目を確認するデモページ（サイト埋め込みの想定） |

管理画面では常に右側に「テスト画面」が表示され、下書きの内容（今はダミーFAQ）でチャットを試せます。

## 確認手順

1. `npm run dev` でローカルサーバーを起動する。
2. `/admin/sources` で、URL・PDF・テキストいずれかの方法で情報を追加し、一覧に「読み込み中…」→「読み込み済み」と表示が変わることを確認する。「チャットで使う」スイッチのON/OFF、削除後の「元に戻す」トーストを確認する。
3. 画面右の「テスト画面」で「お墓じまいの金額・相場は？」などのボタン、または自由入力で質問し、ダミーFAQに一致する回答が返ることを確認する。一致しない質問では「お答えできません」という案内（電話・お問い合わせページへのリンク付き）が返ることを確認する。
4. `/widget-demo` で右下の「AIに相談する」ボタンから同じチャットを開き、見た目がお客さま向けの想定と合っているか確認する。


## 今後（フェーズ2・3、および本実装）

- フェーズ2：よくある質問、答えられなかった質問、話し方・ルール、見た目設定、下書き/公開の分離。
- フェーズ3：公開履歴・ロールバック、メンバー招待、会話ログ。
- 本実装：`src/lib/data/`（データ取得層）と `src/lib/answer/`（回答生成層）の中身を、Supabase・Claude API・Voyage AI 等の実APIに差し替える。呼び出し側のコンポーネントは変更不要な設計にしている。

## 費用の目安について

本フェーズはUI/UXのみの試作のため、外部APIの利用料は発生しません。本実装フェーズ（Supabase / Claude API 等の導入）に進む際に、利用量に応じた費用目安を別途まとめます。
